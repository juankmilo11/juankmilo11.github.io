# PACA · Paula Daniela

Página estática de servicios de belleza publicada en `/pages/paula/`.

Esta carpeta es la única fuente de PACA: editar `index.html`, `css/styles.css`
y `js/app.js` directamente. No necesita compilación ni copias de publicación.
El script controla los filtros de servicios y las animaciones. Las citas
enlazan al perfil de Instagram de Paula.

Para probarla, servir la raíz del repositorio y abrir `/pages/paula/`.
Ver comandos y validación en el [README principal](../../README.md).
